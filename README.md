# CampusMarket — Homepage Prototype

A responsive first-page prototype for a school marketplace built with:
- HTML
- Bootstrap 5
- Vanilla JavaScript
- Firebase-ready structure

## Run locally

Open `index.html` in a browser, or serve the folder with any static server.

## Firebase next step

Edit `js/firebase-config.js` with your Firebase project settings, then add the Firebase Web SDK.

Recommended Firestore collections:
- `users`
- `schools`
- `listings`
- `favorites`
- `messages`
- `reports`

The homepage currently uses local mock data so it works without a backend.

## Design direction

The homepage is intentionally positioned between Facebook Marketplace, eBay and a modern school-community product:
- Large search-first hero
- Category discovery
- Fresh listings grid
- Student/community trust messaging
- Sell-item modal
- Sign-in modal
- Responsive Bootstrap layout
